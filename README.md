# PromptBridge AI

PromptBridge AI is a minimal full-stack AI integration project.

## Architecture

React Frontend → Express Backend → OpenAI API → Response to UI

## Features

- Prompt submission UI
- Secure backend OpenAI call
- Error handling
- Loading states
- Environment-based API key protection

## Tech Stack

- React
- python FASTAPI
- OpenAI SDK

## Why This Project Matters

Demonstrates real-world AI integration using proper client-server separation and secure API handling.
